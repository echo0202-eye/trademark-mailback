# 商标退信查询（Trademark Mailback）

一个只读的 AI 技能：让 Agent 直接查询中国商标局**送达公告（退信）**数据，覆盖 2002 年至今 400 余万条记录。

## 能做什么

| 场景 | 示例提问 |
|---|---|
| 查某公司有没有退信 | 「北京某某科技有限公司有没有商标退信？」 |
| 看退信明细 | 「这家公司名下哪些商标退信了？商标名、注册号、什么类型？」 |
| 判断期限风险 | 「这批退信还在答辩期内吗？」 |
| 拿公告原件 | 「把这条退信公告的原件链接给我」 |

## 安装

### Trae

把本目录作为插件导入（插件市场安装或本地目录加载），技能会自动出现在可用技能列表。

### WorkBuddy / Claude Code

将 `skills/trademark-mailback` 复制到技能目录：

```bash
cp -r skills/trademark-mailback ~/.claude/skills/
```

### 直接使用（不需要 Agent）

```bash
python3 skills/trademark-mailback/scripts/mailback.py search "乐乐农业"
python3 skills/trademark-mailback/scripts/mailback.py detail "乐乐农业（深圳）有限公司"
```

仅依赖 Python 3.8+ 标准库，无需安装第三方包。

## 数据与合规

- 数据来源：中国商标局送达公告等公开信息。
- 仅提供公开信息的检索与整理，不涉及个人隐私数据。
- 只读接口，不会修改、删除任何数据。
- 期限提示仅供参考，不构成法律意见，具体以商标局通知书为准。
- 接口限频：每个 IP 每小时 60 次。
- 脚本内置公共 API Key，仅可访问查询接口；需要更高频次可申请私有 Key，通过环境变量 `ZM_MAILBACK_KEY` 配置。
