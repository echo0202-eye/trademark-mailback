# 商标退信查询

数据来自中国商标局送达公告（2002 年至今 400 余万条），按申请人名称检索。只读，不会修改任何数据。

## 何时使用

- 「XX 公司有没有商标退信？」
- 「这家公司名下哪些商标退信了，分别是什么时间、什么类型？」
- 「帮我看看这几个商标/注册号的退信记录」（先按公司名检索，明细里含商标名与注册号）
- 需要判断某个商标是否可能错过答辩/复审/补正期限

## 用法

```bash
# 1. 按公司名模糊搜索（至少 2 个字）
python3 scripts/mailback.py search "乐乐农业"

# 2. 查看某公司名下全部退信明细
python3 scripts/mailback.py detail "乐乐农业（深圳）有限公司"

# 3. 数据较多时翻页（每页 100 条）
python3 scripts/mailback.py detail "某某有限公司" --offset 100

# 4. 输出原始 JSON，便于二次处理
python3 scripts/mailback.py search "乐乐农业" --json
```

## 输出说明

搜索结果：申请人全名、退信件数、最近期号与日期。
明细结果：公告期号、公告日期、注册号、商标名、发文类型（未识别会标注）、期限状态、原件链接（若有）。

## 使用要点

1. **先搜后查**：`search` 返回的是公司全名，`detail` 要用全名精确查询。
2. **同名公司多**：搜索词尽量具体，用全名最准。
3. **发文类型为空**：表示该条公告的发文类型尚未识别，可提示用户在朱门商标小程序内申请查看。
4. **期限仅供参考**：以商标局通知书载明为准，不构成法律意见。
5. **限频**：每个 IP 每小时 60 次，超限会返回 `rate_limited`，稍后再试。
6. **API Key**：脚本内置公共 Key（只可访问查询接口）。如需私有 Key 或更高频次，设置环境变量 `ZM_MAILBACK_KEY`。

## 数据范围

- 商标局送达公告（退信）公开信息，覆盖 2002 年至今。
- 不含商标申请、注册、续展等非退信业务数据。
